# O.L.I.V.I.A — Online Learning Intelligent Interactive Assistant

[![Python 3.12+](https://img.shields.io/badge/Python-3.12%2B-3776AB?logo=python&logoColor=white)](https://python.org)
[![UI](https://img.shields.io/badge/UI-CustomTkinter-green)](#)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A bilingual (English / Filipino), offline-first desktop learning application that bundles the **Philippine K–12 (DepEd MATATAG)** and **college (CHED)** curricula into a structured library, generates assessments automatically, and tracks learner progress — with a companion **Android web-view app**, a **Figma plugin/spec**, and **LAN classroom networking**.

> **The problem it solves:** Filipino learners — especially those unable to attend school — lack a single offline resource that organizes the curriculum by grade, subject, and difficulty with built-in quizzes and progress tracking. Materials are scattered across online portals, unstructured, and unusable without reliable internet; parents and teachers have no ready-made material for home tutoring; education staff burn out from manual lesson delivery; and parents cannot see what their child is learning.

---

## Features

### 📚 Curriculum Library
- **K–12 (DepEd MATATAG):** Kindergarten → Grade 12 SHS, every learning area per grade.
- **College Programs (CHED):** categorized programs across disciplines (Sciences, Education, Law, Journalism, Sociology, Forestry, and more).
- **Six difficulty tiers per topic:** Full Lesson · Easy · Medium · Hard · Practice · Full Assessment.
- **Visual HTML lessons** with subject-colored banners, inline images and step boxes (extra visual aids for Grades 1–4).

### ✅ Built-in Assessment
- **Auto-generated quizzes** from any lesson: multiple choice, true/false, and fill-in-the-blank.
- Per-question feedback, scores, streaks, badges, and **answer keys** (with a printable all-answers view).

### 📊 Progress, Gamification & Analytics
- Points, streaks, badges, weekly activity, average scores per student.
- Teacher/admin dashboards with **class leaderboards** and per-student analytics.

### 🌐 Offline-first & Networked
- Runs fully offline; all curriculum content is bundled locally (SQLite-backed).
- Optional **LAN peer networking** with a role hierarchy: `King → Admin → Teacher → Student` for classroom progress sharing.

### 👤 Roles & Administration
- **Student / Teacher / Admin** accounts; first-run admin setup; password hashing (PBKDF2) with lockout.
- **Curriculum generator** (full or prompt-based lesson creation), **imported files**, **document & slide editor**, **web search** (DepEd LRMDS / CHED portals), and **backup & restore**.

## Repository Layout

```
├── desktop/        Python desktop application (CustomTkinter) + PyInstaller spec
├── mobile/         Android WebView app + web build tools and asset pipeline
│   ├── android/    MainActivity.java wrapper (WebView host) + launcher icons
│   ├── web/        Mobile web assets (HTML/CSS/JS)
│   └── tools/      build_web.py, pack_apk.py, verify_assets.py, smoke tests
└── figma/          Figma plugin generating the app's UI screens + full UI spec
```

> **Generated content isn't committed.** The thousands of per-lesson/visual HTML pages in `mobile/web` are build output produced from the curriculum source data and are regenerated by `desktop/visual_lessons.py`, `desktop/regenerate_assessments.py`, and the mobile `tools/` pipeline — not stored in git.

## Getting Started (Desktop)

```bash
pip install -r desktop/requirements.txt
python desktop/desktop_app.py
```

> On first run you will create the admin account. The app auto-scans `K-12_Philippine_Curriculum` and `College_Programs` folders next to it; generate or import curriculum content via the **Admin → Generate Curriculum** tab, or add your own markdown files (see `desktop/learning_data.py` for the file naming/tier convention).

### Build a Windows executable

```bash
python desktop/build_desktop.py
```

## Technology

| Layer | Stack |
|---|---|
| Desktop UI | Python · CustomTkinter · tkinterweb (HTML viewer) |
| Data | SQLite (WAL mode) · JSON credentials |
| Auth | PBKDF2-SHA256 (600k iterations), login throttling |
| Assessment | custom quiz engine (MCQ / T-F / fill-blank) |
| Networking | TCP server/client + UDP LAN discovery |
| Mobile | Android WebView (Java) + web assets |
| Packaging | PyInstaller (onedir, windowed) |
